Forge Lite: pruébalo ahora, en el navegador

Las herramientas de limpieza y de mapas de NV Asset Forge funcionan aquí mismo, sin clave ni servidor: tus imágenes no salen de tu ordenador. La generación con IA, los packs y Blender están en la app completa.

Quita el fondo por inundación desde los bordes (con borde suave y sin halo), recorta, y reduce a la rejilla nativa con paleta cerrada por k-means y alfa binario. Cada píxel toma el color dominante de su bloque (no la media), se limpian motas sueltas y se añade contorno. El normal map sirve para luz 2D en Godot (CanvasTexture) y Unity (Sprite Lit): pasa el ratón por la vista "luz 2D".

Hecho con NV Asset Forge

Texturas, fachadas y sprites con FLUX.2 en NVIDIA Build; mundos montados y renderizados en Blender con los scripts del repositorio.

Instalar en 3 pasos

Funciona en cualquier PC. La generación usa tu clave gratuita de NVIDIA Build; el procesado, Blender y la biblioteca se quedan en tu ordenador.

Instala Node.js 18 o superior

Desde nodejs.org (versión LTS). Opcional pero recomendado: Blender para 3D y mundos.

Descarga y arranca

Descomprime el ZIP y haz doble clic en start.bat (Windows) o start.command (macOS), o en una terminal:

git clone https://github.com/aguado435/Nv-asset-forge.git
cd Nv-asset-forge
node server.js

Pega tu clave de NVIDIA

Créala gratis en build.nvidia.com → cualquier modelo → Get API Key, y pégala en Ajustes. Se guarda solo en tu PC.

La API gratuita de NVIDIA Build está pensada para prototipar y evaluar. FLUX.2 [klein] 4B, el modelo de imagen por defecto, se publica con licencia Apache 2.0. Revisa las condiciones de cada modelo antes de publicar un juego.
